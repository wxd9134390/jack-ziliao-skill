# sihai-ziliao · 四海公考资料分析速算体系 Skill

> 一个给 WorkBuddy 用的**行测资料分析解题 Skill**，把四海公考 / 花生十三 2026 系统班「资料分析」模块（11 讲正课 + 答疑 + 总结加课，共 27 个视频）蒸馏成可直接调用的可执行方法论。

---

## 这是什么

它不是题库，也不是视频，而是把老师 16 年培训沉淀出来的**解题套路**结构化后的「能力卡集合」。你问一句「已知基期 100、增速 20%，增长量是多少」，它会按 `ABRX 四量框架` 给你拆：

- 先识别题型（这是哪一类？）
- 再选速算方法（假设分配 / 415 / 化除为乘？）
- 最后给公式与坑点（单位、能不能秒杀、基期推不推）

覆盖：基期/现期/增长量/增长率、**速算三法**、增速比较、百分点/翻番/降幅、平均数与倍数、比值差、比较类（趋势法/双线法/王者荣耀法/替代比较）、线段法/盐水思想、年均增长量与年均增长率、全章易错口诀与学习法。

## 卡片格式

每张 `references/*.md` 遵循统一结构：

- **R (Resource)** — 这个知识点是什么、公式与铁律
- **I (Intent)** — 什么情况下触发
- **A1 (Action)** — 解题/操作的具体步骤
- **A2 (Alternative)** — 备选方法或易错点
- **E (Example)** — 例题
- **B (Boundary)** — 使用边界与禁忌
